# 포트폴리오 범위

이 저장소는 공개 가능한 익명화 현대화 샘플입니다. 실제 고객사 프로젝트의 소스코드, SQL, 계정 정보, 인프라 파일, DB 덤프, 내부 명칭은 포함하지 않습니다.

## 참고한 레거시 구조

참고한 레거시 시스템은 다음과 같은 형태의 공공 하천관리 웹 시스템입니다.

- Java WAR 애플리케이션
- eGovFrame 및 Spring MVC XML 설정
- `WEB-INF/jsp` 아래 JSP 화면
- Oracle/PostgreSQL용 SQL Mapper XML
- 관리자, 권한, 게시판, 수문, 하천 시설, GIS, 뷰어 모듈
- DBMS 자료, 쿼리, 설정, GeoServer 자산이 함께 존재하는 운영형 구조

## 선택한 범위

첫 번째 포트폴리오 범위는 수위 관측입니다. 레거시 수문 메뉴 중 `hydWaterLevels`와 유사한 모듈을 모델로 삼았습니다.

이 범위가 좋은 이유는 현대화 가치가 명확하기 때문입니다.

- cm/m 같은 단위 정규화가 필요함
- 비정상 관측값을 경계에서 거부해야 함
- 관측소 유형별 경보 정책을 분리할 수 있음
- 조회가 많은 화면이라 캐시와 인덱스 전략을 설명하기 좋음
- SQL Mapper row를 도메인 객체로 옮기는 마이그레이션 흐름이 자연스러움

## 공개 기준

이 저장소에 포함해도 되는 것:

- 익명화된 패키지명
- 일반화한 payload 이름
- 단순화한 도메인 객체
- 합성 테스트 데이터
- 아키텍처 다이어그램과 마이그레이션 설명

포함하면 안 되는 것:

- 실제 기관명이나 내부 프로젝트명을 직접 드러내는 표현
- 원본 시스템의 운영 DB 스키마 또는 SQL
- 내부 URL, IP, 계정, 라이선스 파일, 서버 설정
- 개인정보 또는 실제 관측 데이터
- 원본 JSP, Java, XML Mapper 소스의 직접 복사
