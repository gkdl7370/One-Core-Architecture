# 설계 샘플 정리 노트

`One-Core-Architecture`는 완성된 운영 플랫폼이라기보다, 레거시 시스템의 제각각인
규격을 코어 도메인으로 흡수하는 방식을 정리한 설계 샘플입니다.

처음 정리할 때는 DDD, anti-corruption layer 같은 키워드를 많이 사용했는데,
다시 보니 코드 규모에 비해 용어가 앞서 보일 수 있다고 느꼈습니다.
그래서 이 저장소에서는 실제 코드로 확인할 수 있는 범위를 분명히 하는 방향이
좋다고 생각했습니다.

## 현재 코드로 확인할 수 있는 것

- 수자원 관측값을 표현하는 코어 도메인 객체
- 레거시 cm 단위 payload를 표준 m 단위로 바꾸는 mapper
- 지역별 경보 기준을 정책 객체로 분리하는 방식
- 정규화, 검증, 정책 판단을 고정하는 단위 테스트

## 아직 코드로 확인하기 어려운 것

- 완성된 DB 영속성 모델
- Redis 같은 분산 캐시 연동
- 운영 수준의 API
- 여러 레거시 시스템을 end-to-end로 수집하는 흐름

이 저장소는 “전체 시스템을 만들었다”보다 “변경이 잦은 외부 규격을 코어
도메인에서 분리하는 방식을 실험했다”는 톤으로 설명하는 것이 자연스럽습니다.
